# Инструкция по тестированию flow опросника

## Подготовка

1. **Применить миграцию БД:**
   ```bash
   alembic upgrade head
   ```
   Или если alembic не установлен глобально:
   ```bash
   python -m alembic upgrade head
   ```

2. **Проверить переменные окружения:**
   - `BOT_TOKEN` - токен Telegram бота
   - `OPENROUTER_API_KEY` - ключ для OpenRouter API
   - `DB_URL` - URL подключения к PostgreSQL
   - `REDIS_URL` - URL подключения к Redis

## Тестирование полного flow опросника

### Шаг 1: Запуск бота
```bash
python -m app.main
```
Или через uvicorn:
```bash
uvicorn app.main:app --reload
```

### Шаг 2: Тестирование через Telegram

1. **Отправь `/start` боту**
   - Ожидаемый результат: Приветствие с описанием Progressus и запрос согласия на обработку ПД

2. **Нажми "Согласен"**
   - Ожидаемый результат: Переход к первому вопросу опросника (пол)

3. **Выбери пол (Мужской/Женский)**
   - Ожидаемый результат: Запрос возраста

4. **Введи возраст (число)**
   - Ожидаемый результат: Запрос имени

5. **Введи имя**
   - Ожидаемый результат: Приветствие с именем и запрос выбора 3 ценностей

6. **Выбери 3 ценности**
   - Выбери любые 3 ценности из списка
   - Нажми "✅ Готово (выбрано 3)"
   - Ожидаемый результат: Запрос выбора сфер развития

7. **Выбери сферы развития**
   - Выбери одну или несколько сфер
   - Нажми "✅ Готово"
   - Ожидаемый результат: Сообщение "Генерирую персонализированные вопросы..." и первый развернутый вопрос от GPT

8. **Ответь на 5 развернутых вопросов**
   - Отвечай на каждый вопрос текстом
   - После каждого ответа должен появиться следующий вопрос
   - Ожидаемый результат: После 5-го вопроса - запрос выбора ролевой модели

9. **Выбери ролевую модель**
   - Выбери одну из 5 моделей (Эндрю Тейт, Михаил Гребенюк, Хабиб, Олег Тиньков, Тайлер Дёрден)
   - Ожидаемый результат: Запрос цели на 3 месяца

10. **Введи цель на 3 месяца**
    - Опиши конкретную цель (минимум 10 символов)
    - Ожидаемый результат: Сообщение "Генерирую твой персональный роадмап..." и затем роадмап с 4 этапами

11. **Проверь роадмап**
    - Должен отобразиться роадмап с 4 этапами:
      - НЕДЕЛЯ 1-2
      - НЕДЕЛЯ 3-4
      - НЕДЕЛЯ 5-8
      - НЕДЕЛЯ 9-12
    - Каждый этап должен содержать: Цель, Результат, Действия

12. **Проверь первое ДЗ**
    - После роадмапа должно появиться сообщение "Генерирую твое первое персональное задание..."
    - Затем должно появиться первое ДЗ уровня 0
    - ДЗ должно соответствовать первому этапу роадмапа

### Шаг 3: Тестирование проверки ДЗ

1. **Отправь отчет о выполнении ДЗ**
   - Напиши текст отчета (более 10 символов)
   - Ожидаемый результат: Сообщение "Оцениваю твой отчет..." и затем обратная связь

2. **Проверь два сценария:**

   **Сценарий А: ДЗ выполнено хорошо**
   - Ожидаемый результат:
     - Сообщение "✅ Красавчик! Ты проделал отличную работу!"
     - Обратная связь
     - Новое ДЗ для следующего уровня (если уровень повышен)
     - Или новое ДЗ для того же уровня

   **Сценарий Б: ДЗ выполнено плохо**
   - Ожидаемый результат:
     - Сообщение "⚠️ Меня не устраивает проделанная работа..."
     - Обратная связь с критикой
     - Правки к текущему ДЗ
     - Требование переделать задание

3. **Проверь цикл правок**
   - Отправь новый отчет после правок
   - Если выполнил хорошо - должно появиться новое ДЗ
   - Если снова плохо - должны быть новые правки

## Проверка данных в БД

После завершения опросника проверь, что в БД сохранены:

1. **Таблица `users`:**
   - `name`, `gender`, `age` - персональная информация
   - `values` - массив из 3 ценностей
   - `development_spheres` - массив сфер развития
   - `goal_3months` - цель на 3 месяца
   - `roadmap` - JSON с роадмапом
   - `personality` - ключ ролевой модели
   - `current_homework` - первое ДЗ
   - `level` - должен быть 0

2. **Таблица `surveys`:**
   - `basic_answers` - JSON с базовыми ответами
   - `detailed_answers` - JSON с развернутыми ответами
   - `detailed_questions` - JSON с вопросами от GPT
   - `role_model` - выбранная ролевая модель
   - `goal_3months` - цель на 3 месяца
   - `roadmap` - JSON с роадмапом

3. **Таблица `reports`:**
   - После отправки отчета должна появиться запись с:
     - `report_text` - текст отчета
     - `gpt_feedback` - обратная связь от GPT
     - `is_approved` - True/False в зависимости от качества
     - `revision_required` - True если требуются правки

## Возможные проблемы и решения

1. **Ошибка при генерации развернутых вопросов:**
   - Проверь `OPENROUTER_API_KEY`
   - Проверь подключение к интернету
   - Проверь лимиты API

2. **Ошибка при генерации роадмапа:**
   - Убедись, что цель на 3 месяца достаточно подробная
   - Проверь логи бота

3. **Ошибка при сохранении в БД:**
   - Проверь, что миграция применена
   - Проверь подключение к БД
   - Проверь логи

4. **Дублирование обработчиков:**
   - Убедись, что в `app/main.py` правильно подключены роутеры
   - Проверь, что нет конфликтующих обработчиков
