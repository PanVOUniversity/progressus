Progressusbot Documentation
=============================

Документация Telegram бота для личного развития.

Progressusbot - это Telegram-бот для личного развития по трём направлениям:
заработок, здоровье, ментальное состояние.

Описание проекта
----------------

Telegram-бот для личного развития с функционалом:

* Опросник из 5 вопросов для определения "болей" пользователя
* GPT-анализ ответов и рекомендация категории развития
* Система уровней (0-10) с прогрессом
* Платный доступ (299 руб) с заглушкой для тестирования
* Ежедневные задания и отчеты
* Реферальная система (/ref)
* Согласие на обработку персональных данных

Технологический стек
--------------------

* Python 3.12
* aiogram 3.22.0 (async Telegram Bot API)
* FastAPI 0.115.0 (webhook сервер)
* PostgreSQL 16 (база данных)
* Redis 7.4 (FSM storage и Celery broker)
* OpenRouter API (GPT-4o-mini через OpenRouter для персонализации)
* Celery 5.4.0 (фоновые задачи)
